Pawgents

One line on a client's site catches what breaks for real visitors. A relay removes secrets and groups repeats, then an agent reproduces the problem with a failing test, fixes it and opens a draft pull request. A developer reviews it. Nothing merges by itself.

The loop

    

      
1 · Catch
embed/pawgents.js or the WordPress plugin. Last 12 visitor steps kept for reproduction. One report per problem per page.

      
2 · Relay
relay/worker.js on Cloudflare, or node relay/serve.mjs. Checks origin or signature, redacts, fingerprints, one fix attempt per problem per day.

      
3 · Fix
.github/workflows/pawgents-fix.yml. Claude Code writes a failing test, the smallest fix, runs tests three times, opens a draft PR, or an issue when it cannot reproduce.

    

  


  

    
Run the whole loop

    

      
git clone https://github.com/Cyril-WP/pawgents-prototype && cd pawgents-prototype
npm run demo                       # shop on :8732, relay on :8787 (dry run)
GITHUB_TOKEN=$(gh auth token) npm run demo   # really starts the fixer workflow

      
Open http://localhost:8732/demo-shop/, break something, and watch the relay terminal. Add an ANTHROPIC_API_KEY repository secret and the workflow opens a real draft PR against the bug in demo-shop/cart.js. Without it the run records the report and stops.
